# 视频素材多模态检索系统

> 输入一句话（如"找一个雨天车窗前的镜头"），返回相关视频片段及时间点。
> 纯 CPU 运行，复用成熟开源组件。

这是根据师兄的《需求规格说明书》搭建的项目仓库。当前处于 **阶段一（基准实验）之前的第一步**：先把元数据解析跑通。

## 快速开始

在项目根目录打开终端（地址栏输入 `cmd` 回车），运行：

```bash
python scripts/probe_video.py
```

成功的话你会看到样片的元数据：时长、分辨率、编码、SHA-256 等。
也可以指定任意视频：`python scripts/probe_video.py 你的视频.mp4`
