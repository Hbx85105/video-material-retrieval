# 提问模板（卡住时照着填）

> 为什么要用模板？因为"我的代码跑不起来"这种问题，别人没法帮你。
> 但按下面三块给信息，AI 基本一次就能定位问题。

---

## 模板

```
【我想做什么】
（一句话说清目标，例如：我想读取视频的时长）

【我试了什么】
（贴出你运行的命令或代码，例如：
python scripts/probe_video.py
）

【完整报错】
（把终端里的报错一字不差地复制过来，不要只截一句。
  Windows 里可以：在终端窗口标题栏右键 → 标记 → 选中文字 → 回车复制）

【环境】
Python 3.13.14 / Windows / 在项目根目录运行的
```

---

## 完整示例

```
【我想做什么】
我想运行 probe_video.py 读取样片元数据。

【我试了什么】
python scripts/probe_video.py

【完整报错】
Traceback (most recent call last):
  File "scripts/probe_video.py", line 60, in <module>
    main()
  File "scripts/probe_video.py", line 50, in main
    report = probe(p)
RuntimeError: ffprobe 执行失败：...

【环境】
Python 3.13.14 / Windows / 在项目根目录运行的
```

---

## 三条规矩

1. **卡 30 分钟就问**，不要一个人耗一整天。
2. **报错要贴原文**，不要转述成"它说找不到文件"。
3. **AI 给了答案后**，跑通了要回来读一遍代码，问自己"它改的是哪一行，为什么"。

问 AI 时的开场白可以这么说：

> 我是 Python 零基础，请用新手能懂的话解释，并给出可以直接复制运行的完整命令。
