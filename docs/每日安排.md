# 每日安排（前 14 天）

> 用法：每天开始看一眼"今天"，做完一项打个勾。卡住就用 `提问模板.md`。
> 目标不是"学完"，是"每天有个能提交的东西"。

---

## 第 1 天：把项目跑起来，学会 git 提交（今天）

- [ ] 打开项目文件夹：在 `video-material-retrieval` 文件夹的地址栏输入 `cmd` 回车
- [ ] 运行 `python scripts/probe_video.py`，看到样片元数据输出
- [ ] 打开 `scripts/probe_video.py`，对照中文注释读一遍，圈出读不懂的行
- [ ] 把输出里的 SHA-256 抄到 `docs/学习日志.md`
- [ ] 初始化 git：`git init`
- [ ] 第一次提交：
  ```
  git add .
  git commit -m "第一天：跑通视频元数据探针脚本"
  ```
- [ ] （选做）注册 GitHub，建一个同名仓库，把本地仓库推上去。命令在 `学习路线.md` 的"Day 1 补充"里。

**今天的验收**：终端能看到元数据输出 + git 有第一条提交记录。

---

## 第 2 天：读懂 ffprobe，改造脚本

- [ ] 手动跑一条 ffprobe 命令，看原始 JSON：
  ```
  ffprobe -v error -print_format json -show_format -show_streams data/samples/sample_test.mp4
  ```
- [ ] 对照脚本，找到 "duration" "codec_name" "width" 分别是怎么变成报告里的字段的
- [ ] 小任务：给报告加一个字段"文件创建时间"，从 `format.tags.creation_time` 取值
- [ ] 提交：`git commit -am "第二天：报告增加创建时间字段"`

**今天的验收**：能说出 ffprobe 输出和脚本字段的对应关系。

---

## 第 3 天：批量处理 + 异常处理

- [ ] 往 `data/samples/` 放 3 个不同视频（手机拍的、下载的都行）
- [ ] 运行脚本，确认能一次性处理多个文件
- [ ] 故意放一个坏文件（比如改后缀的 txt），确认脚本不会整体崩溃
- [ ] 提交一次

**今天的验收**：一个坏文件不会让整个脚本挂掉。

---

## 第 4–5 天：Python 基础补漏（按需，哪里不懂补哪里）

只学这几样，别贪多：
- 变量、列表、字典：能看懂 `report["分辨率"]` 这种写法
- 函数：能看懂 `def xxx():` 和 `return`
- 循环：能看懂 `for p in paths:`
- 文件读写：`open()` 的基本用法

推荐：B 站搜"Python 基础 语法"，挑一个播放量高的，只看这几节，边看边在脚本上改。

- [ ] 学完在 `学习日志.md` 记一句今天学了什么

---

## 第 6–7 天：阶段一基准实验（重头戏）

目标是产出《CPU 推理基准报告》，这是师兄文档里点名的"当前首要工作"。

- [ ] 装 PyTorch CPU 版：`pip install torch --index-url https://download.pytorch.org/whl/cpu`
- [ ] 写脚本 `scripts/bench_torch.py`：测你的 CPU 跑一次矩阵乘法多久
- [ ] 记录硬件信息：CPU 型号、核心数、内存（Windows 任务管理器 → 性能页可以看到）
- [ ] 把结果写进 `docs/基准报告.md`，模板见 `学习路线.md`

**验收**：能填出"CPU 型号 / 核心数 / 一次运算耗时"三项硬数据。

---

## 第 8–10 天：Chinese-CLIP 单图编码

- [ ] 按 `学习路线.md` 的步骤下载 Chinese-CLIP RN50 权重（这一步可能卡，卡住就发提问模板）
- [ ] 写脚本：加载模型 → 读取一张关键帧 → 输出一个向量（一串数字）
- [ ] 确认同一张图两次运行结果一样（这就是需求里的"确定性"）
- [ ] 提交一次

**验收**：能打印出一个 1024 维（或模型规定维度）的向量。

---

## 第 11–14 天：串起 MVP1 最小链路

- [ ] 用 FFmpeg 从一个视频里抽 3 张帧：`ffmpeg -i xxx.mp4 -vf fps=1 frame_%03d.jpg`
- [ ] 把 3 张帧编码成向量
- [ ] 装 Qdrant：`pip install qdrant-client`，用本地模式
- [ ] 把向量存进 Qdrant
- [ ] 写一个查询：输入"红色"之类简单的词，看能不能召回对应的帧

**验收**：输入简单中文词，能返回一张相关的帧图片。到这一步 MVP1 的最小链路就通了。

---

## 通用每日节奏（不管做哪天都用）

| 时间段 | 做什么 |
| --- | --- |
| 开始 10 分钟 | 打开这个文档，看今天的任务，读一遍要改的代码 |
| 中间 60–90 分钟 | 动手改代码 / 跑命令，卡住 30 分钟就用提问模板 |
| 结束 10 分钟 | 在 `学习日志.md` 写三行：今天做了什么 / 卡在哪 / 明天做什么 |
| 最后 | `git add` + `git commit`，哪怕只改了一个字 |
