## 二、这学期的配比（重要：和前几天不一样了）

**期末考试有死线，项目没有死线。** 所以：

- **主线 = 专业课**（数据结构 + JAVA），工作日每天约 2 小时，跟着考试节奏走
- **保温线 = 项目**，工作日 30–45 分钟推一小格，周末有整块时间再加 2–3 小时冲一格
- 项目不能停超过 3 天，否则捡起来要重来

## 三、三条线分别怎么学

### 数据结构（最难，去年挂科率高，重点投入）

- **主线网课**：B 站「蜂考」数据结构速成（同学验证过能考过，就跟着它，不换来换去）
- **铁律**：看视频只占 3 成，**做题占 7 成**。每看完一节，立刻做对应习题；只看题不做 = 假懂
- **顺序**：复杂度 → 线性表 → 栈和队列 → 串/数组 → 树与二叉树 → 图 → 查找 → 排序
- **每天**：约 1 小时（比 JAVA 多，因为它难）

### JAVA（很基础，期中考过，压力小）

- **不额外加码**：跟着老师布置的作业、练习、实验走就行
- **每天**：约 30–45 分钟
- 重点：语法 → 面向对象 → 集合 → 异常 → IO。老师布置什么就练什么

### 项目（保温线）

- 每天打开 `每日安排.md`，做当天那一格，做完 `git add .` + `git commit`
- 卡住 30 分钟就用 `提问模板.md` 的三段式问我

### 老师作业（待补充）

> 学习通的作业/练习/实验我暂时看不到（见对话说明）。你把作业截图或文字发我，我就填进来并按它调整每天的格子。在这之前，JAVA 和数据结构按上面通用路线走。

## 四、每日固定任务（照着勾，做完就停）

**工作日**

- [ ] 数据结构：蜂考 1 节 + 对应习题（约 1 小时）

**周末**

- [ ] 数据结构：复习本周 + 做一套综合题（约 1.5 小时）
- [ ] JAVA：完成本周实验（约 1 小时）
- [ ] 项目：用整块时间冲完一整格（2–3 小时）
- [ ] 写一条周总结进学习日志
