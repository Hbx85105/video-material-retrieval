## 二、这学期的配比（11-21 更新：JAVA 不期末考）

**只有数据结构有期末死线，JAVA 不考、项目也没死线。** 所以：

- **绝对主线 = 数据结构**，工作日每天 1–1.5 小时，跟着蜂考节奏走，最难、投入最多
- **顺带线 = JAVA**，每天 20–30 分钟，只过最基础语法，不为考试、只为打底
- **保温线 = 项目**，工作日 30–45 分钟推一小格，周末整块时间冲一格
- 项目不能停超过 3 天，否则捡起来要重来

## 三、三条线分别怎么学

### 数据结构（绝对主线，最难，去年挂科率高）

- **主线网课**：B 站「蜂考」数据结构速成（同学验证过能考过，就跟着它，不换来换去）
- **铁律**：看视频只占 3 成，**做题占 7 成**。每看完一节，立刻做对应习题；只看题不做 = 假懂
- **顺序**：复杂度 → 线性表 → 栈和队列 → 串/数组 → 树与二叉树 → 图 → 查找 → 排序
- **每天**：1–1.5 小时

### JAVA（不期末考，顺带学最基础）

- **目标降级**：不用为考试刷题，把最基础语法过一遍、打底就行
- **每天**：20–30 分钟，学一个小点就停
- **顺序**：变量/类型 → if/for → 数组 → 方法（函数）→ 面向对象入门（类和对象）
- 注意：数据结构优先，JAVA 只做最低限度，别占主线时间

### 项目（保温线）

- 每天打开 `每日安排.md`，做当天那一格，做完 `git add .` + `git commit`
- 卡住 30 分钟就用 `提问模板.md` 的三段式问我

### 老师作业（待补充）
